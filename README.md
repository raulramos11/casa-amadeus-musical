# Casa Amadeus Musical — Demonstração de e-commerce

Página de demonstração (estática) para uma loja de instrumentos musicais, com visual
de e-commerce: catálogo de produtos, busca, carrinho e fluxo completo de checkout
(entrega **ou** retirada na loja, pagamento com cartão/PIX e confirmação de pedido).

Tudo roda no navegador, sem backend — é uma demonstração. Preços e produtos são fictícios.

## Como rodar localmente

Abra o `index.html` diretamente no navegador, ou sirva a pasta:

```bash
npx serve .
# ou
python3 -m http.server 8099 --bind 127.0.0.1
```
